## Goal

Building a 20-song set takes about 40-50 actions instead of 110-130: tick songs in a filtered checklist (or multi-select them in the Library), arrange them by keyboard or drag, split a gig into parts with break rows, and see truthful totals that include changeovers and point at exactly the songs still missing a length.

## Steps

0. **Design directions (R39 style):** 2-3 renders of the builder with the Pick | Arrange control, the checklist rows, the live total bar, a break row with its part total, and the missing-lengths popover (light and dark). Also fix the clipped filter-chip rows in the builder and library columns (fade or scroll affordance; brainstorm pixel nit). Ryan picks before step 2.
1. **Core: break entries + changeover + parts timing.** `SetlistEntry` gains a break kind (label; optional length per question 22, blocked until Ryan rules, recommendation: optional, counted in the whole total only); `Setlist` gains `changeoverSeconds: Int?` (nil = global default); schema version bump with the `VersionedJSON` rule (a newer file opens read-only in older builds; older files load unchanged). `SetlistTiming` computes per-part totals (songs + changeovers after every song but the last of each part + unknown count) and the whole; the phase 2 notation is unchanged; at-most-once ignores break rows. The global default lives in a small settings store (Settings > General "Changeover between songs", default 0 s). Show-end `ReorderDiff` and duplicate handling keep break rows intact.
2. **Arrange mode:** set alone, full width; ⌥↑ / ⌥↓ move the selected rows (multi-row selection in the set list), drag kept, `SetEntryEditor` popover kept; Insert Break (Setlist menu + context menu; label "Set N" numbered automatically, editable); break rows show their part total; builder undo covers every action (R16).
3. **Pick mode:** the library column becomes a checklist (checkbox per row); Space or click ticks the focused row; ↑/↓ move focus; Return in the filter field moves focus to the first result; **⌘A ticks every row the current filter shows** (songs already in the set stay ticked, nothing is added twice); a tick appends to the end of the set (or the end of the selected part, if a break row is selected in Arrange); unticking removes that song's entry. P3-6's smart filters work as filter inputs here when landed. Live total bar: target, total, the "N unknown" button.
4. **Library multi-select:** `SelectableList` gains a multi-selection mode (⌘-click toggle, ⇧-click range, ⇧↑/⇧↓ extend; single click still single-selects; the brand styling unchanged) used by the main Library list; Add to Setlist (menu, context menu, existing shortcut) adds every selected song in list order, skipping songs already in that setlist, and reports "Added 7 songs, 2 were already in the set". The detail pane shows "N songs selected" with Add to Setlist (coordinate with P3-10, who owns `SongDetailPane.swift`). Only Add to Setlist acts on a multi-selection in 0.5; other commands keep acting on the focused song.
5. **Missing-lengths list (R88):** every "N unknown" (header, part totals, Pick total bar) is a button; its popover lists exactly the songs without a length in set order, each with P3-5's `LengthField` (writes `{duration}` through the editor path, one undo step) and Open Song (selects it and calls P3-10's `focus(.length)`). The count updates live as lengths are filled. If P3-10 has not landed, ship the inline field and add Open Song when it lands.
6. **Live side of break rows:** the show and rehearsal handle a break entry per question 21 (blocked until Ryan rules; recommendation a: a stage interstitial "Break - Set 2 starts with <song>", Next continues, the clock keeps running, the gig log records it). Keep this to `ShowRecord`/`ShowController` item handling and the stage interstitial view; P3-14 and P3-15 build on it in wave 3.
7. **Menus:** the Pick/Arrange toggle and Insert Break get menu items and shortcuts in `MenuShortcuts.all` (the clash test must pass; you are the only wave 2 owner of `MenuShortcuts.swift` and `SetlistCommands.swift`); the `?` overlay lists them automatically.
