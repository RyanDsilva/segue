# Segue - Brand & Design System

Canonical brand spec. Chosen 2026-10-17: direction **C "Precise"** with the **"Taped setlist"** icon. Source mockups live on the design canvas https://claude.ai/artifact/XizqyqzA1chVfBSGThAzcQ (artboards "C Precise - Brand", "C Precise - Stage view", "C - Icon concepts"); values below are copied from those artboards and win over memory.

## 1. Idea

**Chart + cue.** Segue is the sheet you tape to the stage and the light that tells you you're on. Tagline: *"Your chart, your set, your cue."*

Personality: crisp, quiet, precise (Linear, Things), with the seriousness of a pro music tool (Logic, Ableton). One colour carries meaning - the coral **cue** - and it is used sparingly: the thing that is live, next, or needs you.

## 2. Name

- Product: **Segue**. App Store title: **"Segue - Setlists & Chords"**. Bundle ID `dev.ryandsilva.segue`.
- Trademark notes live in `00-vision.md` and `decisions.md` (manual USPTO check before any paid launch).

## 3. Wordmark

- "Segue" set in **Schibsted Grotesk ExtraBold (800)**, letter-spacing **-0.045em**, line-height 1.
- Followed by the **cue dot**: a coral (`cue`) circle, diameter about 0.22 of the cap height (14px at 64px type), top-aligned with a small offset (8px at 64px).
- Never recolour the word; the dot is the only colour. On dark grounds the word is `paper`/`#ECECEE`, the dot stays `cue`.
- **Font licence:** Schibsted Grotesk is SIL Open Font License 1.1 (Google Fonts; source github.com/schibsted/schibsted-grotesk). OFL permits bundling in the app, including App Store builds. Ship the static weights we use (400, 500, 600, 700, 800) in `SegueUI` resources, register via `CTFontManagerRegisterFontsForURL`, and include `OFL.txt` in the app's acknowledgements. Do not rename or sell the font files.

## 4. App icon - Taped setlist

Geometry in a 100x100 grid (squircle `rx 23`; the system mask governs the final shape):

| Layer | Spec |
|---|---|
| Background | `ink #111113` (dark/default); `#F2F2F4` in the light variant |
| Sheet | rect x27 y20 w46 h64 rx3, `paper`; whole sheet+tape group rotated **-6deg** around (50,52) |
| Title line | rect x34 y32 w24 h5 rx2, `ink` |
| Setlist lines | 4 rects h3 rx1.5 at y44/53/62/71, widths 30/26/32/22, `#9A9AA2` |
| Gaffer tape | rect x37 y14 w26 h11 rx1, `cue #F2555A`, overlapping the sheet top |

Variants:

- **Dark/default:** white sheet on ink.
- **Light:** ink sheet on `#F2F2F4`, lines `#8A8A92`, title line white.
- **Tinted:** monochrome, generated by the system from the layered file. Check that the tape stays distinct by lightness.

Small sizes are hand-tuned rather than scaled:

- **32px:** three lines only, each 5 units thick, with a wider tape (x36 y13 w28 h12).
- **16px:** the sheet (x25 y20 w50 h66) and the tape (x35 y11 w30 h15) only, with no lines.

**Production:** build the icon as a macOS 26 **Icon Composer `.icon` file** with three Liquid Glass layers, back to front:

1. background (solid ink);
2. sheet with its lines (a flat SVG group);
3. tape (separate layer, so the glass specular sits on the tape).

Export each layer as SVG from a master file in `design/icon/` (git-tracked). Check in `design/icon/Segue.icon` and reference it from the Tuist app target. Verify in Icon Composer's light, dark, tinted and clear previews and at Dock/Finder/menu sizes before commit. Phase 0 ships it.

## 5. Colour tokens

| Token | Light UI | Dark stage | Use |
|---|---|---|---|
| `cue` | #F2555A | #F2555A | live/next indicators, icon tape, wordmark dot - non-text only on light |
| `cueText` | #C42B30 | #FF6B6F | text in the accent, chord symbols |
| `ink` / `text` | #111113 | #ECECEE | primary text |
| `ground` | #FFFFFF (`paper`) | #101113 (`stage`) | window and live view background |
| `muted` | #55555C | #8E8E96 | secondary text, section labels, metadata |
| `line` | #E4E4E7 | #222326 | hairlines and dividers (decorative) |
| `controlBorder` | #E4E4E7 | #8E8E96 at 40% | outline of secondary buttons, chips, steppers, pills; Increase Contrast #8A8A92 / #66676E |
| `played` | #55555C | #8E8E96 | played-song progress dots |
| `lineStrong` | #B9B9C0 | #2A2B2F | icon greys, piano black keys (not state indicators) |
| `indicatorOff` | #8A8A92 | #66676E | off state of indicators: pending progress dots, unrated stars |
| `surfaceAlt` | #F2F2F4 | #1A1B1E | light icon ground, hovered rows |

Contrast, measured with WCAG 2.x:

- **Text pairs that pass AA:** ink on paper 18.9:1; `cueText` on paper 5.6:1; muted on paper 7.4:1; text on stage 16.0:1; stage chord on stage 6.8:1; dark muted on stage 5.8:1.
- **`cue #F2555A` on paper is 3.4:1.** That passes for non-text UI and large text only, so never use it for body or chord text on light. Use `cueText` instead.
- **`cue` on stage is 5.6:1.** It's fine for dots and indicators.
- **Lines are decorative,** at 1.2-1.3:1. Never rely on a line alone to convey state. Control outlines reach 3:1 under Increase Contrast (`controlBorder`, see 7).
- **State indicators reach 3:1 (2026-10-17, A44):** pending dots and unrated stars use `indicatorOff` (3.43:1 on paper, 3.36:1 on stage); played dots use `played` (7.39:1 on paper, 5.81:1 on stage); the current pill is `cue` (3.37:1 / 5.60:1). On the always-dark stage the order reads by lightness: pending 3.36 < played 5.81, with current as a coral pill.
- **Paired states must differ in lightness or shape, not hue alone.** Proficiency marks use fill and outline (see 7).

## 6. Type scale (Schibsted Grotesk)

| Role | Size / weight | Notes |
|---|---|---|
| Display (wordmark, onboarding) | 64 / 800, -0.045em | |
| Title (song title, window headers) | 28-34 / 800, -0.035em | live header 28 |
| Section heading | 20 / 700 | library, settings |
| UI body | 15 / 500-600 | buttons, lists, chips 14 / 600 |
| Label | 13 / 700 | section labels, captions, metadata |
| **Live lyric** | default 24 / 400, line-height 1.25 | user-set minimum, default **22pt**; auto-fit never goes below it, scrolls instead |
| **Live chord** | 0.82 x lyric size / 700, `cueText` | at the 22pt floor that is 18 / 700 |

Editor and PDF use the same chord/lyric ratio so what you edit is what you see on stage.

## 7. Components

- **Chips (key / capo / BPM):** 14 / 600 text, padding 5x10, radius 6, 1px `line` border, no fill. Key chip shows just the key ("G").
- **Proficiency marks:** 8px dot plus label, 14 / 600. **Learning** is an outlined ring (2px, `#8E8E96`), **Ready** a filled grey dot, **Pro** a filled ink dot (white on stage). The states differ by fill and lightness, not hue.
- **Buttons:** primary has an ink fill with paper text; secondary is paper with a `line` border. 15 / 600, padding 10x18, radius 8. Coral is never a button fill; it is reserved for the cue.
  - **Control border in dark (2026-10-17):** dark `line` (#222326) is 1.2:1 against `stage`, so secondary buttons, steppers, chips and chord pills disappear. Their 1px outline uses the `controlBorder` token: `line`'s value in light, `muted` at 40% in dark (about #424246, 1.9:1). Hairlines and dividers keep `line`.
  - **Control border under Increase Contrast (A43, 2026-10-17):** with Increase Contrast on, `controlBorder` is #8A8A92 / #66676E (3.43:1 / 3.36:1), the `indicatorOff` values. The default look is unchanged; Apple's Sufficient Contrast criteria accept the Increase Contrast setting for apps built on Apple's frameworks (quote in `docs/release/accessibility-audit.md`). `design/tokens.json` carries these as `lightHigh` / `darkHigh`, generated into the asset catalog's High Contrast appearances.
- **Section label gutter (live view):** a 64px left column holding the label at 13 / 700. Chorus labels use `text`, other sections `muted`. Collapsed repeats render "Repeat chorus" in muted at lyric size.
- **Set progress dots:** a row of 6x6 radius-3 dots in the live header.
  - Played songs: `played` (#55555C light, #8E8E96 stage).
  - Current song: a 20px-wide `cue` pill.
  - Upcoming songs: `indicatorOff` (#66676E on stage).
  - Skipped songs: a 1.5px `played` ring (shape, not hue).
  - Elapsed set time sits beside the dots in muted.
- **Header:** cue dot, song title (28 / 800), then key, capo and tempo as one muted line ("G, capo 2, 96").
- **Next-song footer:** a 1px `line` top border.
  - "Up next" (14 / 700 muted), then the title (20 / 700), then key and capo (muted).
  - On the right: the auto-scroll state, and the request count with a cue dot.

## 8. Motion

Minimal and functional. Transitions between songs are a fast cross-fade (150 ms or less) or none. Auto-scroll is linear and continuous. Nothing pulses, bounces or loops on stage, and the cue dot never blinks. All motion respects Reduce Motion, and in live mode non-essential animation is disabled outright.

## 9. Implementation plan (SwiftUI)

- **Phase 0:**
  - The `SegueTheme` module in `SegueUI` holds colour tokens as Asset Catalog colour sets with Any/Dark appearances, generated from one `tokens.json` in `design/` so docs, PDF export and app share values.
  - It also holds typed `Color`/`Font` accessors (`Theme.color.cueText`, `Theme.font.liveLyric(size:)`) and the bundled-font registration.
  - The app icon `.icon` file also ships in phase 0.
  - An integration test renders a token swatch view in light and dark and checks the colour values resolve.
- **Phase 1:** the editor and chord diagrams use the theme's chord/lyric styles, so there are no hard-coded colours.
- **Phase 2:** live view components (gutter, progress dots, header, footer) and the stage theme, including the min-font rule.
- **Phase 4:** the PDF renderer reads the same tokens, using the light palette.
