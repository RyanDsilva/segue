Keyboard shortcuts

Segue is built to be played from the keyboard.

Main window and menus

KeyDoes
Cmd-NNew Song
Cmd-RRefresh the library
Cmd-SSave the song you're editing
Cmd-,Settings

Stage mode

KeyDoes
Right Arrow or SpaceNext song
Left ArrowPrevious song
Down Arrow or Page DownScroll down
Up Arrow or Page UpScroll up
HomeBack to the top
AStart or pause auto-scroll
[ and ]Slower and faster auto-scroll
Cmd-K or /Search the library
RPlay the next request
QShow requests
XSkip the song
SShow the set order
CChange the number of columns
OCollapse repeated sections
Cmd-+ and Cmd--Zoom in and out
Cmd-0Actual size
Cmd-.End the show
EscClose the open panel
