Your library

Your library is a folder of plain files. Segue reads it, indexes it for search, and never locks it away.

Where songs live

Inside your library folder, Segue keeps:

  • songs/: one ChordPro file (.cho) per song, with a small .segue.json file beside it for Segue's extras such as tags, proficiency and notes;
  • setlists/: one file per setlist;
  • shows/: your gig log, one file per show.

To use a different folder, choose Library > Choose Library Folder. You can't switch libraries while a show is running.

Tags and proficiency

Each song has a proficiency mark, Learning, Ready or Pro, and any tags you add. The marks differ by fill, not by colour alone.

Finder integration

Backing up and exporting

Your library is a normal folder, so Time Machine and any other backup tool already cover it. To move it to another Mac, copy the folder and choose it there.

Rebuild Index

If search results look wrong, choose Library > Rebuild Index. Segue rebuilds its search index from your files. It never changes the files themselves.
