Shortcuts

Let a Shortcut quiet your Mac when the show starts, and bring it back afterwards.

Gig Mode Shortcuts

Gig Mode Shortcuts are off until you set them up. In the Shortcuts app, make a Shortcut called "Gig Mode On" that uses the Set Focus action, and another called "Gig Mode Off". Then in Settings > Live, under Gig Mode Shortcuts, choose them for On show start and On show end. Press Test to try each one.
