Files that can't be read

If a song file in your library can't be read, Segue shows how many were skipped above the song list, and lists them. Skipped files are left untouched in the library folder.

A file that isn't UTF-8 text opens read-only, shown with Segue's best guess at its encoding. Convert it to UTF-8 to edit it.
