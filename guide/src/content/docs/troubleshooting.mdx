## Search looks wrong {#search}

Choose **Library > Rebuild Index**. It rebuilds the search index from your files and never changes them.

## A file can't be read {#files}

Segue says how many files were skipped above the song list; click it to see which and why. A file that isn't UTF-8 text opens read-only with Segue's best guess at its encoding: convert it to UTF-8 to edit it.

## AI isn't available {#ai}

**Settings > AI** says why and links to the right place in System Settings. Segue still converts every paste with its own rules. See [AI in Segue](/guide/ai).

## A Gig Mode Shortcut doesn't run {#shortcuts}

Press **Test** in **Settings > Live**. If macOS blocked it, see [Gig Mode Shortcuts](/guide/gig-mode#permission).

## Segue didn't offer to resume a show {#resume}

Segue offers to resume only a show that was still running when it quit. A show you ended is in the [gig log](/guide/gig-log).

## Still stuck? {#support}

Write to us from the [Support page](/support). A real person answers, usually within a few days.
