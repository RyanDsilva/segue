## The slash menu {#slash}

In Text mode, type <kbd>/</kbd> at the start of a line and pick by plain name: Verse, Chorus, Bridge, a note, Movie / Album, or a value such as Key or Tempo. With lines selected, a section wraps them.

## Completion {#completion}

Typing <kbd>[</kbd> suggests chords already in the song. Typing <kbd>{"{"}</kbd> suggests directives, including the section names, and offers values for keys and tempos.

## Key check {#key-check}

If a directive holds a value Segue can't read, like a key written `Hm`, the editor flags the line and offers a fix.

## ChordPro in six lines {#chordpro}

ChordPro is plain text. Chords go in square brackets right before the syllable they belong to, and directives in curly braces set the title, key and sections:

```text
{title: Lanterns}
{key: G}
{start_of_verse}
[G]Lanterns on the [D]water, the [Em]boats come [C]in
[G]Ropes along the [D]railing, the [C]night begins
{end_of_verse}
```

Because the files are standard ChordPro, any other ChordPro app can open them.
