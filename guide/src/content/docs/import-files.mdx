## Supported files {#formats}

ChordPro files (`.cho`, `.chordpro`, `.chopro`, `.pro`) import as they are. Plain text (`.txt`) and `.crd` files are converted the same way as a paste.

## Drag them in {#drag}

Drag files or whole folders onto the song list. Or choose **File > Import Songs…** (<kbd>⇧⌘I</kbd>) and pick them.

One import takes up to 500 song files, from folders up to 16 levels deep. Text saved as UTF-16 (Windows Notepad's "Unicode") is converted to UTF-8 as it is copied.

## Files that need converting {#batch}

Text and `.crd` files open one review sheet with a preview of each converted song and a checkbox beside it. Untick any you don't want, then click **Import**. Unticked files are not imported.

A combined artist in a converted file is split into one artist each, as for a [paste](/guide/paste-a-song#artists), with **Keep as one** to undo the split. ChordPro files keep their artists exactly as written.

## Imports are copies {#copy}

Segue copies each file into your library folder. The original stays where it was, untouched. A song that is already in the library is skipped.

When a file or a paste looks like a song you already have (a similar title, the same artist, much the same words), the review sheet says so under the song: "Looks like “Deewana” by Kumar Sanu in your library." It is only a hint: you can still import it. A ChordPro file that looks like a library song opens in the review sheet for this, exactly as it is, while other ChordPro files still import at once.

## Open With Segue {#open-with}

In Finder, open a `.cho` file with Segue to copy it into your library.

## Files that can't be read {#problems}

If a song file in your library can't be read, Segue says how many were skipped above the song list. Click it to see which files and why. Skipped files stay untouched in the library folder.
