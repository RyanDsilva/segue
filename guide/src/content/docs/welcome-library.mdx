When you open Segue for the first time, the Welcome cards walk you through choosing a library folder and add the Welcome songs: "Soundcheck at Seven", "Kitaabon Wali Gali", "Kettle On, Lights Low" and "Ferry Lights Over Calder Bay", by Segue Originals, plus a setlist called **Welcome Set**.

<Shot id="welcome-cards" alt="The Welcome card that adds the Welcome songs" />

Play with them: transpose them, build a set, take them on stage. Each one already has a key and a tempo, so the Welcome Set has a full running time.

## Remove the Welcome songs {#remove}

Delete them one by one like any song, or choose **Settings > Data > Remove Welcome Songs…**. Songs you have edited stay. **Add Welcome Songs** brings them back.

## See the Welcome cards again {#welcome-cards}

Choose **Help > Welcome to Segue…**.
