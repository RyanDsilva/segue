Choose **Section Notes…** from the editor or the song's menu, pick a section, and type a note.

<Shot id="notes-sheet" alt="The Section Notes sheet with a note on Chorus" />

## Show on stage only {#stage-only}

Notes show in the chart everywhere by default, written into the song file. Turn on **Show on stage only** to keep a note off the printed chart and see it only during a show. A stage-only note pins to a named section, so it stays with that section when you edit the song.
