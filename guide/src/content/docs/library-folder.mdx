## What is in the folder {#files}

| Folder | What it holds |
| --- | --- |
| `songs/` | One ChordPro file (`.cho`) per song, with a small `.segue.json` file beside it for tags, proficiency and notes |
| `setlists/` | One file per setlist |
| `shows/` | Your gig log, one file per show |
| `filters/` | Your smart filters |

Time Machine and any other backup tool already cover it. To move your library to another Mac, copy the folder and choose it there.

Segue keeps its search index and its locks on this Mac, outside the folder, so only your files travel with it. A copy of the folder becomes a library of its own: the first time you open the copy, Segue says so once.

## iCloud Drive, Dropbox and other synced folders {#file-sync}

A library can live in iCloud Drive (including Desktop and Documents in iCloud), Dropbox, Google Drive, OneDrive or Box, and Segue opens it like any other folder. These services can move files off your Mac to save space and bring them back only when they are opened, so a song might not be there at a gig, with no network.

When your library is in one of these folders, a note at the top of the song list says so. **Learn More** opens this page; **Don't Show Again** hides it for that library on this Mac. **Settings > Data** keeps the same line while it applies.

For shows, keep your library in a folder on this Mac, such as one in your Music folder, and copy it to move it to another Mac (see above). If you keep the library in a synced folder anyway, set the folder to stay downloaded (in Finder, Control-click it and choose **Keep Downloaded**, where your service offers it).

## Use a different folder {#change}

Choose **Library > Choose Library Folder…**, or **Settings > Data**. You can't switch libraries while a show is running.

## Search {#search}

Type in the search field above the song list. Segue searches titles, artists, movies and albums, and every lyric line, so a half-remembered line is enough. Romanized Hindi spellings match each other: "pyar" finds "pyaar".

## Finder {#finder}

**File > Show in Finder** (<kbd>⌥⌘R</kbd>) reveals a song's file. `.cho` files open in Segue from Finder, Quick Look previews them, and Finder's icon and gallery views show each chart's title and first lines.

Drag a song out of the library list to send it: drop it on a Finder folder to save a copy of its `.cho`, or into a Messages chat to send the chart to your bass player. The song stays in your library. Dragging is off while a show is up.

## When search looks wrong {#rebuild}

Choose **Library > Rebuild Index**. Segue rebuilds its search index from your files and never changes the files themselves.
