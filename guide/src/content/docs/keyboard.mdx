## More keys {#editing}

| Where | Key | Does |
| --- | --- | --- |
| Visual editor, lines selected | <kbd>V</kbd> <kbd>C</kbd> <kbd>B</kbd> <kbd>I</kbd> | Make a verse, chorus, bridge or intro |
| Builder, Pick | <kbd>Space</kbd> | Tick or untick a song |
| Builder, Pick | <kbd>⌘A</kbd> | Tick the filtered list |
| Builder, typing a song (<kbd>⌘L</kbd>) | <kbd>Return</kbd> | Add the suggested song, or the break for `---` |
| Builder, typing a song | <kbd>↓</kbd> <kbd>↑</kbd> or <kbd>Tab</kbd> <kbd>⇧Tab</kbd> | Next or previous suggestion |
| Builder, typing a song | <kbd>Esc</kbd> | Close the suggestions, then clear the line |
| Builder, last song selected | <kbd>↓</kbd> | Go to the row for typing a song |
| Assistant, a selected song | <kbd>Space</kbd> | Why this song |
| Quick search on stage | <kbd>Return</kbd> | Play now |
| Quick search on stage | <kbd>⌥↩</kbd> | Play next |
| Quick search on stage | <kbd>⌘↩</kbd> | Add to requests |
| Song card, Time it | <kbd>Esc</kbd> | Cancel timing |
| Artists | <kbd>Return</kbd> or <kbd>,</kbd> | Add the typed artist, exactly as typed |
| Artists | <kbd>↓</kbd> then <kbd>Return</kbd>, or <kbd>Tab</kbd> | Add the suggested artist |
| Artists, nothing typed | <kbd>⌫</kbd> twice | Remove the last artist |
| Play along, a chord selected | <kbd>1</kbd>-<kbd>9</kbd> | Make it that many beats |
| Play along, a chord selected | <kbd>&lt;</kbd> | Push it an eighth or a sixteenth early, or back on the beat |
| Play along, a chord selected | <kbd>⇧←</kbd> <kbd>⇧→</kbd> | Select a run of chords |
| Play along, dragging a chord's edge | <kbd>⌥</kbd> / <kbd>⌥⇧</kbd> | Snap to eighths / sixteenths |
| Tap Timing | <kbd>Space</kbd> or <kbd>Page Down</kbd> | The next chord starts now (hold <kbd>⌥</kbd> for half a beat) |
| Tap Timing | <kbd>Tab</kbd> | Skip a chord: it keeps its length |
| Tap Timing | <kbd>Esc</kbd> | Stop; in the review, discard |
| Tap Timing review | <kbd>Return</kbd> | Keep the tapped lengths |
